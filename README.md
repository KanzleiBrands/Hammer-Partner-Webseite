# Hammer & Partner mbB – Website

Next.js 16 · Tailwind CSS 4 · Keystatic CMS · Motion · Hosting auf Vercel

```bash
npm install
npm run dev     # http://localhost:3000  (CMS: /keystatic)
npm run build
npm run lint
```
